# *Feel free to use the checklist template below!*
## Structure
- [ ] Clear title and author
- [ ] Scenario included
- [ ] Artifacts listed
- [ ] Tools used listed
- [ ] Methodology section present
- [ ] Each question answered in a consistent format
- [ ] Timeline included
- [ ] MITRE mapping included if relevant
- [ ] Conclusion included

## Evidence Quality
- [ ] Every answer is backed by log evidence
- [ ] Commands are shown clearly
- [ ] Output is explained, not just pasted
- [ ] Findings match the answer exactly
- [ ] No unsupported assumptions

## Timeline / Time Handling
- [ ] Timezone is identified
- [ ] Timestamps are normalized to UTC
- [ ] Session start and end times match log evidence
- [ ] Any offset is explained

## Forensic Methodology
- [ ] Relevant artifact chosen for each question
- [ ] Filters/search terms are appropriate
- [ ] Cross-log correlation is performed when needed
- [ ] Persistence and privilege escalation are identified separately
- [ ] Final command execution is supported by log evidence

## Writing Quality
- [ ] Professional tone
- [ ] Concise wording
- [ ] Minimal repetition
- [ ] Typos corrected
- [ ] Clear headings and spacing
- [ ] No unnecessary filler

## Note Readiness
- [ ] Could another analyst reproduce the findings?
- [ ] Are the steps logical and sequential?
- [ ] Does the write-up show understanding, not memorization?
- [ ] Can each answer be defended verbally if asked?
